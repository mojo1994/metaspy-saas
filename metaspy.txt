 RESUMO DA ARQUITETURA
====================================================================

  Front-end:  React 18 + TypeScript + Vite 5 + Zustand + React Router
              Deployment: Netlify (static)

  Back-end:   Express.js + Puppeteer + BullMQ + Redis + SQLite/PostgreSQL
              Deployment: Render

  Cloudflare: Worker "metaspy-host" (Browser Rendering + R2 bucket)
              wrangler.toml configura binding BROWSER + METASPY_BUCKET

  Pages clonadas:    Armazenadas no R2 (metaspy-pages)
  Autenticação:      JWT (bcryptjs)
  Pagamentos:        Kirvano (webhook)
  Filas:             BullMQ (Redis) para thumbnails
  Bypass engine:     4 linguagens (JS/TS/PHP/Python)
  Total de arquivos: ~85 (excluindo node_modules, .wrangler, dist)
